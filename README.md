# FFmpeg Tool

Windows installers and online update feed. This repository contains no application source code.

## Download

[Download the latest installer](https://github.com/toantran1007/ffmpeg-tool-releases/releases/latest)

## Updating from 1.0.0

Install 1.1.0 manually once. The older 1.0.0 app does not include online updates.
Close the customer app before installing; existing license data is retained.
From 1.1.0 onward, use the update button in the app to check, download, and install updates.
The app does not install updates while processing videos.

A valid license key is required to process videos. The installer does not include Admin tools.
